# IEEE LaTeX report

- `Cancer_Classification_IEEE_Report.tex`: editable IEEEtran conference-format source.
- `Cancer_Classification_IEEE_Report.pdf`: compiled PDF.
- `figures/`: figures referenced by the source.

The repository version omits student registration numbers from the author block for portfolio privacy. The project report in this folder remains an academic, non-clinical evaluation.

To compile from this directory with a TeX Live installation:

```bash
pdflatex Cancer_Classification_IEEE_Report.tex
pdflatex Cancer_Classification_IEEE_Report.tex
```
